# Проекты

Основной опыт: production-портал коробочной Битрикс24 в крупном таксопарке (сотни ТС и водителей) - ~15 кастомных приложений, 70+ фоновых агентов, интеграции с мессенджерами, почтой, телефонией и внешними сервисами. Плюс мобильные приложения поверх REST API портала и маркетплейс-приложения для Битрикс24.

Рабочий код заказчика не публикуется (коммерческая разработка). Открытые репозитории - демо-приложения и шаблоны, выложенные в [профиле](https://github.com/Ksuproject). Рабочие демо - по запросу.

## Приложения внутри портала Битрикс24

**Автопарк** - центральная система учёта парка: канбан ТС, водителей и документов; штрафы, полисы, диагностические карты; контроль сроков; дедупликация карточек; дашборды. Полноценное staging-окружение для безопасных доработок.

`PHP` `JavaScript` `REST API` `MySQL` `Kanban`

**Вкладка и планировщик в карточке сделки** - встраиваемые приложения: привязанные ТС, документы, планирование выдачи и возврата авто без выхода из сделки.

`PHP` `JS-виджеты` `CRM placement`

**Учёт страховых полисов** - реестр ОСАГО/ОСГОП, контроль сроков действия, автоматические напоминания ответственным и водителям.

`PHP` `REST API` `Уведомления`

**Пробеги и ТО (GPS)** - интеграция с GPS-провайдером: ежедневный пробег каждого ТС, контроль межсервисных интервалов, напоминания о техобслуживании.

`PHP` `REST API` `Cron` `Внешний API`

**Модуль ДТП** - сквозной процесс работы с инцидентами: чат-бот, загрузка и разбор файлов, пользовательские поля и виджеты в задачах.

`PHP` `JS` `Открытые линии` `UF-поля`

**Кнопки и баннеры в карточке сделки** - кастомные действия и контекстные баннеры через init.php-обработчики и JS.

`PHP` `init.php` `JS`

**Чат-виджет сайта** - виджет на сайте, связанный с открытыми линиями портала, с кабинетом управления.

`PHP` `JS` `Открытые линии`

**Путевые листы** - публичная выдача путевых листов водителям по защищённым токен-ссылкам без авторизации на портале.

`PHP` `Токен-доступ`

## Интеграции и открытые линии

- **WhatsApp** - приём сообщений через webhook-провайдера в открытые линии, мониторинг коннектора с автоуведомлением о сбоях
- **Avito** - прямой канал сообщений в открытые линии с роутингом в сделки
- **Универсальный коннектор** - единый мессенджер-коннектор для подключения каналов к открытым линиям
- **Телефония** - робот-обзвон по регламентным событиям (осмотры ТС)
- **Почта** - IMAP-импорт: штрафы, балансы, обращения, резюме кандидатов - с разбором вложений (XLSX, MIME) и созданием сущностей CRM

`REST API` `Webhooks` `IMAP/MIME` `Коннекторы открытых линий`

## Фоновая автоматизация (70+ агентов)

- **Документооборот ТС:** приём файлов из открытых линий и Диска, распознавание диагностических карт и полисов, привязка к карточкам, автозадачи на нераспознанные документы
- **Контроль сроков:** диагкарты, полисы, ТО, осмотры, возвраты - цепочки напоминаний и эскалаций
- **Сделки:** синхронизация стадий, автоназначение ответственных, возвраты в воронку продаж, архивация, закрытие неактивных
- **Дедупликация:** поиск и слияние дублей контактов и сделок с отчётами
- **Рассылки:** документы водителям при закреплении ТС, массовые уведомления, регулярные опросы пользователей портала
- **Системные:** lifecycle доступа внешних пользователей, мониторинг коннекторов, бэкап-триггеры, обёртка cron-оркестрации

`PHP` `Агенты Битрикс` `cron` `Batch-обработка`

## Инфраструктура и DevOps

- **Мониторинг** - Prometheus + Grafana + blackbox exporter, кастомные экспортёры метрик (nginx, php-fpm, MySQL, Redis), ~30 алертов в Telegram, генератор дашбордов
- **Бэкапы** - ежедневные дампы БД, полные бэкапы, проверка восстановления
- **CI/CD** - деплой через GitHub Actions по SSH: бэкап, заливка, `php -l`, атомарная замена файлов
- **Миграция портала** - перенос коробки на новый сервер: nginx, php-fpm, MySQL, Redis, поиск, push-server, SSL; с документированной инструкцией
- **Тюнинг** - php-fpm под нагрузкой (устранён свопинг), InnoDB buffer pool

`Linux` `nginx` `php-fpm` `MySQL` `Redis` `Prometheus` `Grafana` `GitHub Actions`

## Работа с данными

- **Дедупликация CRM** - полный цикл: отчёт по дублям, план слияния, дамп затронутых строк, пробный прогон, выполнение через API портала, лог «старое/новое» для отката
- **Аудиты данных** - заполненность полей, сделки без контактов, дубли по воронкам, зависшие сущности
- **Документация** - архитектурные схемы (mermaid), реестр интеграций и вебхуков, внутренние шпаргалки для команды

`SQL` `Data audit` `Dry-run` `Документирование`
